# 指标系统 V2 集成测试指南

## 🎯 测试目标

验证 V2 架构在真实图表环境中的表现，确保与旧版功能一致。

## 📋 测试准备

### 1. 启动开发服务器

```bash
npm run dev
```

### 2. 配置测试环境

创建两个终端窗口，分别测试新旧两版：

**终端 1 - 旧版（默认）**
```bash
# .env.local
NEXT_PUBLIC_USE_INDICATOR_V2=false
```

**终端 2 - V2 版**
```bash
# .env.local
NEXT_PUBLIC_USE_INDICATOR_V2=true
```

## 🧪 测试用例

### 测试 1: 基础渲染
- [ ] 打开图表页面
- [ ] 检查 K线图是否正常显示
- [ ] 检查默认指标是否渲染（通常是 MA）
- [ ] 检查控制台是否有错误

**预期结果**:
```
[useKlineChart] ✅ USE_INDICATOR_V2 is ENABLED  (V2)
[useKlineChart] ❌ USE_INDICATOR_V2 is DISABLED (旧版)
```

### 测试 2: 所有指标类型
依次启用每个指标，检查渲染效果：

- [ ] **MA** (主图) - 多条不同颜色的均线
- [ ] **EMA** (主图) - 多条不同颜色的指数均线
- [ ] **BOLL** (主图) - 上中下三条轨道
- [ ] **RSI** (副图) - 单独 Pane，多条 RSI 线
- [ ] **MACD** (副图) - DIF/DEA 线 + 柱状图
- [ ] **KDJ** (副图) - K/D/J 三条线
- [ ] **VOL** (副图) - 成交量柱状图（红绿区分）

**检查点**:
- 颜色是否正确
- 位置是否正确（主图/副图）
- 数值是否合理
- Pane 高度是否合适

### 测试 3: 多指标组合
- [ ] 同时启用 MA + BOLL (主图)
- [ ] 同时启用 RSI + MACD + KDJ (副图)
- [ ] 启用全部 7 个指标

**检查点**:
- 主图指标叠加是否正常
- 副图 Pane 是否独立创建
- 性能是否流畅（无卡顿）

### 测试 4: 指标切换
- [ ] 启用 MA → 切换到 EMA
- [ ] 关闭 RSI → 对应 Pane 是否删除
- [ ] 修改 MA 参数 (5, 10, 20) → (7, 25, 99)

**检查点**:
- 旧指标是否完全移除
- 新指标是否立即显示
- 参数变化是否立即生效
- Pane 管理是否正确

### 测试 5: 周期切换
- [ ] 从 1h 切换到 1d
- [ ] 从 1d 切换到 15m
- [ ] 快速切换多次（压力测试）

**检查点**:
- 指标是否重新计算
- 缓存是否生效（第二次加载更快）
- 是否有内存泄漏（控制台监控）

### 测试 6: 实时数据更新
- [ ] 观察 K线实时更新
- [ ] 指标是否跟随更新
- [ ] 最新数据点颜色是否正确

**检查点**:
- 更新频率是否正常（1-5秒一次）
- 指标值是否平滑变化
- 无闪烁或跳动

### 测试 7: 性能对比

**旧版**:
1. 打开 DevTools Performance 面板
2. 录制 10 秒性能数据
3. 记录 FPS 和内存使用

**V2 版**:
1. 相同操作
2. 对比结果

**预期**:
- FPS: >= 50 (两版相近)
- 内存: V2 可能略高（缓存占用）
- CPU: V2 第二次加载应更低（缓存命中）
