## 🐛 已知的 UI 小问题

### 1. 首次加载闪烁 ⚠️
**现象：** 页面首次加载时，K线图区域会短暂显示"加载中..."骨架屏  
**原因：** 动态导入（dynamic import）+ Suspense  
**影响：** 不影响功能，仅视觉体验  
**解决方案：** 添加页面级 Loading 动画

### 2. 搜索框聚焦边框 ⚠️
**现象：** 点击搜索框时，紫色边框可能被其他元素遮挡  
**原因：** z-index 层级问题  
**影响：** 轻微视觉问题  
**解决方案：** 调整 z-index

### 3. 订单簿滚动条样式 ⚠️
**现象：** 浏览器默认滚动条样式  
**影响：** 与整体设计不协调  
**解决方案：** 自定义滚动条 CSS
